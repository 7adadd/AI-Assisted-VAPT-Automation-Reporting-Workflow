# VAPT Engagement Report Template

## 1. Executive Summary
- Engagement Overview & Scope
- Risk Posture & Severity Distribution Table (Critical / High / Medium / Low / Informational)
- Top Business Risks
- Strategic Recommendations
- AI-Assistance & Human-Validation Disclosure (Ethics Rule E7)

## 2. Scope, Rules of Engagement & Methodology
- Targets & Environments (Isolated Lab Only)
- 5-Layer AI-Assisted VAPT Workflow (Ingest -> Grounded Prompt -> Local LLM -> Validation Gate L1–L4 -> Reporting)
- CVSS v3.1 Rating Scale

## 3. Summary of Validated Findings
| ID | Title | Domain | Asset / Endpoint | CVSS v3.1 Score | Severity | Validation Level |

## 4. Detailed Technical Findings
For each finding:
- Finding ID & Title
- Severity & Verified CVSS v3.1 Vector
- Affected Asset / Component
- Description
- Steps to Reproduce (verified commands / HTTP requests / line numbers)
- Proof / Evidence (screenshots / tool output)
- Impact
- Specific Remediation

## 5. Prioritized Remediation Roadmap
- Immediate (0–7 days)
- Short-Term (30 days)
- Strategic (90 days)

## 6. Appendix — AI Validation & Accuracy Summary
- Validation Coverage %
- Cross-Model & Human QA Summary
